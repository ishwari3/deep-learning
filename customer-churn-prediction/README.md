# Customer Churn Prediction using ANN

A hands-on Deep Learning project that uses an Artificial Neural Network (ANN) to predict customer churn.

## What This Notebook Covers
- Loading and exploring the Churn Modelling dataset.
- Removing irrelevant identifier columns.
- Encoding categorical features using one-hot encoding.
- Splitting the dataset into training and testing sets.
- Applying feature scaling using StandardScaler.
- Building and training an ANN using TensorFlow and Keras.
- Generating predictions and evaluating classification accuracy.
- Visualizing training and validation loss and accuracy.

## Model Architecture
- Input layer: 11 features
- Hidden layers: Two dense layers with 11 neurons each
- Output layer: One neuron with sigmoid activation

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- TensorFlow and Keras

## Learning Objective
To understand how an ANN can learn patterns from customer data and perform binary classification to predict whether a customer is likely to leave the bank.
