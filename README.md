# Perceptron Learning Algorithm

A beginner-friendly implementation and animation of the Perceptron Learning Algorithm using Python.

## Features
- Generates a binary classification dataset using `scikit-learn`
- Implements the perceptron algorithm from scratch using NumPy
- Visualizes the decision boundary using Matplotlib
- Animates how the decision boundary changes during learning

## Technologies Used
- Python
- NumPy
- Matplotlib
- scikit-learn
- Jupyter Notebook

## How to Run
1. Clone this repository.
2. Install the required libraries:

   ```bash
   pip install numpy matplotlib scikit-learn jupyter
   ```

3. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open `perceptron_trick.ipynb` and run the cells.

## Learning Objective
To understand how a perceptron learns to classify data points by updating its weights and decision boundary.
