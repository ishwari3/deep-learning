# Perceptron Loss Function

A hands-on exercise exploring the Perceptron Learning Algorithm through dataset generation, weight updates, and decision boundary visualization.

## What This Notebook Covers
- Generating a binary classification dataset using `make_classification`.
- Implementing the perceptron algorithm from scratch.
- Updating weights and bias based on classification errors.
- Calculating the slope and intercept of the decision boundary.
- Visualizing the resulting decision boundary alongside the data points.

## Implementation
The notebook uses a simple perceptron with two input features, a learning rate of `0.1`, and iterative weight updates. Matplotlib is used to visualize the classification data and the learned decision boundary.

## Libraries Used
- NumPy
- Matplotlib
- scikit-learn

## Learning Objective
To understand how perceptron weight updates influence the decision boundary and how a linear classifier separates data points.
