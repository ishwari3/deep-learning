# Perceptron Trick

A hands-on learning exercise exploring the Perceptron Learning Algorithm using Python.

## What I Learned
- How a perceptron updates its weights based on classification errors.
- How a decision boundary separates data points into classes.
- How the decision boundary changes as the perceptron learns.

## Tools Used
- Python
- NumPy
- Matplotlib
- scikit-learn
- Jupyter Notebook

## Visualization
The notebook includes an animation showing how the decision boundary evolves during the learning process.

## Purpose
This exercise is part of my personal journey to understand machine learning and deep learning concepts through practical experimentation.
